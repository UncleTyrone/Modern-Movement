# `features/dash.py`

Dash start, Eternal-style host hold (`host_apply_dash` / `_HOST_DASHES`), local predict, damage reduction / perfect dodge, pip + arrow HUD wiring, camera shake/lean/push options. The hold rewrites horizontal speed only. A ground skim is applied once at the start. Later ticks and the soft stop pass `z=None` so a joiner's fall is not snapped back by the host. If the pawn is walking again during the hold, physics is set back to falling so run speed does not clamp the burst. Joiners use the same cooldown as a local dash, and a host digest with `cooldown_left` 0 does not clear the ready hex.
