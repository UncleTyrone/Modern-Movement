# `features/surfacefx.py`

Cosmetic dust, wind, and impact rings for both games. Each game has its own particle list. A missing effect is skipped, and movement does not wait on it.

A dash kicks up the surface you left and leaves wind in the air. Sprinting leaves a light streak. A slide scrapes the ground you are on. A slam lands in a circle plus impact dust. Spawn is a particle system, a location, and a rotator.
