# `features/surge.py`

Sprint Surge ramp, indicator arcs, camera tilt slider, block flicker when action skills deny the boost. `ramp_slider` is seconds to climb from +30% to +70% of the run you already have, sprint included (0 instant, 10 longest). It is not a 10x multiplier. `server_speed_mult` carries that 1.30–1.70 boost, not a run speed.
