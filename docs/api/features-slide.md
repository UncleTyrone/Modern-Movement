# `features/slide.py`

Sprint-crouch slides. Network path: CrouchedPct decay plus `_coast_slide` on the entry direction (`host_enter_juso(..., distance_percent, dir_x, dir_y, speed_percent)`). `_distance_scale` lengths the decay. `_speed_scale` multiplies coast speed only (default 120). The coast push is `_COAST_PUSH`, and the crouch cap matches that speed. Host service and PlayerMove post both re-apply the coast. The owning client ends the slide on crouch release (`stood up` → `server_slide_exit`); the host copy does not cancel from a missing `bDuck`.

A slide jump stores `state.chain` with direction, speed, and `at`. While that chain is set, `DuckPressed` is blocked and `chain_blocks_slam()` keeps Borderlands 2 slam from arming, so the held crouch is not an Oz slam or a custom slam. On landing, `offer_landing` starts the next slide only when `_chain_air_ok` is true (`core.clock - at >= _CHAIN_MIN_AIR`, 0.40s). A new in-air crouch press banks `slam_bank`; `Landed` or slam `_impact` calls `offer_landing` with that speed when crouch is still held. `release_player` drops holds on respawn or travel. Slide indicator HUD. No Mesh.Z dips.
