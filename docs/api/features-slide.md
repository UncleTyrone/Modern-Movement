# `features/slide.py`

Sprint-crouch slides. Network path: CrouchedPct decay plus `_coast_slide` on the entry direction (`host_enter_juso(..., distance_percent, dir_x, dir_y, speed_percent)`). A sustained drop (`_track_drop` past 0.12s) slows that decay and uses `_MAX_DOWNHILL_S`. One Z sample does not. `_distance_scale` lengths the decay. `_speed_scale` multiplies coast speed only (default 120). The coast push is `_COAST_PUSH`, and the crouch cap matches that speed. Host service and PlayerMove post both re-apply the coast. The owning client ends the slide on crouch release (`stood up` → `server_slide_exit`); the host copy does not cancel from a missing `bDuck`.

A slide jump stores `state.slide_jump`. `state.chain` stays armed while `crouch_down` is set. That latch is set on DuckPressed and cleared on DuckReleased. A PressedKeys miss does not clear it, because that list omits a crouch key that is still held. The normal landing slide is blocked for 3 seconds after the jump, so the crouched pose cannot start another slide. A timed joiner slide still ignores a one-frame crouch-flag flicker. While that chain is set, `DuckPressed` is blocked on the owning client only, and `chain_blocks_slam()` keeps Borderlands 2 slam from arming, so the held crouch is not an Oz slam or a custom slam. `_authority_tick` does not run that input machine on a joiner's server pawn. The host coast stays in `_HOST_SLIDES`. A joiner slide jump calls `server_slide_jump(vx, vy, vz)`. The host drops the coast, stands the crouch up, and holds that launch in `_HOST_JUMPS` for `_LAUNCH_HOLD` (0.15s). While the pawn is already rising, later ticks write horizontal speed only. On landing, `offer_landing` starts the next slide only when `_chain_air_ok` is true (`core.clock - at >= _CHAIN_MIN_AIR`, 0.40s). A sprint jump with no slide before it stores the fastest horizontal speed in `state.air_slide` while `_crouch_held` is True. Landing calls `_air_crouch_landing`, which slides when that speed meets Min Slide Speed and the key is still down. `offer_landing` passes `core.facing` and the saved speed into `_start`, which stores that direction itself. For `_LAND_GRACE` (0.35s) the landing slide ignores stall, back-cancel, a sprint edge, and a one-frame hop, and PlayerMove gets the new coast written back. A slide jump does not use that path. An unreadable key does not slide. A new in-air crouch press banks `slam_bank`; slam `_impact` calls `offer_landing` when the crouch key reads down, using the faster of the dive carry and `air_slide`. Holding the key keeps the slide if the crouch pose drops for a frame. `release_player` drops holds on respawn or travel. Slide indicator HUD. No Mesh.Z dips.
