# Options

Each feature exposes `OPTIONS` (GroupedOption children) and optional `KEYBINDS` / `HOOKS`. Nested Settings come from `core.settings(children, description)`.

Indicators that ship with toggles: Dash Screen Effect, Dash Ready Indicator, Perfect Dodge Effect, Jump Counter (default Off), Slide Indicator, Sprint Surge Indicator.

Camera feel sliders live in Settings for Dash, Double Jump, Slide, Mantle, and Sprint Surge. Values are per client; co-op RPCs pass strength/distance when authority must honour the requester.
