# HUD indicators

ECHO-coloured feedback around the crosshair. Dash arrows, the ready pip, the slide bar, and the surge arcs draw on the game HUD. The HUD images are in this package. Borderlands 2 and The Pre-Sequel each use the texture loader that matches that game, so you do not install texloader yourself. If an image cannot be created, that mark draws with lines. Jump Counter stays off until you turn it on. Slam brackets are Borderlands 2 only.

| Indicator | Feature setting | Default |
|-----------|-----------------|---------|
| Dash arrows | Dash Screen Effect | On |
| Dash ready pip | Dash Ready Indicator | On |
| Perfect dodge burst | Perfect Dodge Effect | On |
| Jump counter | Jump Counter | Off |
| Slide bar | Slide Indicator | On. It shrinks across the slide and is gone when the slide ends. |
| Sprint Surge arcs | Sprint Surge Indicator | On |
| Slam brackets | Slam Indicator | On, Borderlands 2 only |

Every shipped indicator has its own On/Off toggle under that feature's Settings.
