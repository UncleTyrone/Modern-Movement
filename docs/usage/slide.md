# Slide

Crouch while sprinting to slide, then let go. The slide keeps the direction you entered with until it slows down. Momentum carries into slide jumps.

On co-op, CrouchedPct still times the slide and your Slide Distance (%) still scales that time. Releasing forward does not stop it: the joiner and the host both keep rewriting speed along the entry direction. Juso's own slide ends when movement input drops; this package does not.

Settings: distance, indicator, audio, camera push/shake, and the usual friction / boost / cancel toggles.
