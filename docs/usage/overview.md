# Usage overview

Enable **Modern Movement** in the mod menu. Each feature is its own page with an Enabled toggle and a Settings submenu. Key bindings sit at the bottom of the mod options — check them after install.

The same package runs in Borderlands 2 and The Pre-Sequel. Double Jump, Dash, Mantle/Vault, Slide, Surface effects, Holster, and Sprint Surge load in both. Slam loads in Borderlands 2, where the game has no Oz slam. The Pre-Sequel keeps the native slam. Holding crouch through a slide jump slides again on landing after the jump has been in the air; a new crouch press in the air still slams. Turn any loaded feature off independently.
