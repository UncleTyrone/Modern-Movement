# Usage overview

Enable **Modern Movement** in the mod menu. Each feature is its own page with an Enabled toggle and a Settings submenu. Key bindings sit at the bottom of the mod options — check them after install.

The same package runs in Borderlands 2 and The Pre-Sequel. Double Jump, Dash, Mantle/Vault, Slide, Surface effects, Holster, and Sprint Surge load in both. Slam loads in Borderlands 2, where the game has no Oz slam. The Pre-Sequel keeps the native slam. Holding the crouch key through a slide jump slides again on landing after the jump has been in the air. Letting go before landing does not. A new crouch press in the air still slams. That crouch check is on your own machine, so it does not block the other players. A joining client sends dash, slide, and jump to the listen host, so those moves are not limited to the weapon holster. Turn any loaded feature off independently. A session log, `Modern_Movement.log.txt`, is written in the same folder as the mod.
