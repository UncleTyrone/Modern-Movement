# Security Policy

## Supported versions

Only the latest `Modern_Movement.sdkmod` built from this repository is supported.

## Reporting a vulnerability

Open a private report or email the maintainer listed on the GitHub release. Do not file public issues that include exploit steps against live game services.

## Scope

This project is a client-side Willow2 SDK mod for Borderlands 2 and Borderlands: The Pre-Sequel. It does not ship network services. Please report:

- Accidental inclusion of credentials, private keys, or personal paths in commits
- Packaging bugs that ship unintended binary payloads
- Co-op authority bugs that let a client force movement on another peer without host validation

Out of scope: general Borderlands game exploits, Gearbox services, or third-party mod loaders.
