# Frozen packages

These files are the supplied originals. Builds write `dist/Modern_Movement.sdkmod` and do not replace anything in this folder.

| File | What it is |
|------|------------|
| `borderlands-2.sdkmod` | The original Borderlands 2 package. SHA-256 `d9431034750f6a8739841220a60a8da391f5a20772eb3affb3fedb4c8774278e`. |
| `borderlands-2/Modern_Movement/` | That package's source. The archive stores the folder as `Modern Movement`. The code is unchanged. |
| `borderlands-2/textures/` | The original loose HUD textures. |
| `pre-sequel-3.61.2.sdkmod` | The shipped Pre-Sequel 3.61.2 package. SHA-256 `4f7c1fbeda6bc75e1d624123e323f109e716fc0d3b0ca2026939aee1919a2429`. |

The live package is `src/Modern_Movement` at version 3.62.0. Install `dist/Modern_Movement.sdkmod`, not these archives.
